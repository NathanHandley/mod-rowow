## Description
AzerothCore server mod to support Ragnarok Online content.

In addition to this mod, Ragnarok Online client data must also be converted by the ROWOWConverter tool.

## Features

- Ragnarok Online creatures (creature_template ScriptName `ROWOW_CreatureScript`) stand on and move along the ground like RO
  monsters: random walks, chasing and idle positions are kept on the terrain with paths of small ground-snapped steps
